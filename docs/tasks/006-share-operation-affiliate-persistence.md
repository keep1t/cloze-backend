## Implementation contract

- Inputs, types, validation, and synthetic examples:
  - Atomic service-only creation function input: authenticated owner UUID, UUID `operation_id`, SHA-256 token hash, non-secret token key-version identifier, explicit `expires_at`, and zero or more already-sanitized affiliate associations.
  - Affiliate item shape: `{ garment_ref: string, url: string, position: integer }`.
  - Synthetic example: `{ garment_ref: "look-item-2", url: "https://shop.example/products/blue-shirt", position: 1 }`.
  - Database constraints enforce nonblank bounded structural values, unique ordering per share, and cascade removal with the parent share. Business limits come from validated application configuration and are not embedded as unexplained constants.
- Outputs/errors and edge-case behavior:
  - First operation creates one pending snapshot, its operation mapping, and all affiliate rows atomically.
  - Same owner plus same operation returns the existing share identity without creating rows.
  - Same operation UUID under a different owner does not reveal the first owner's share.
  - Conflicting immutable inputs for an existing owner/operation return a typed conflict rather than mutating the original operation.
  - Cleanup bookkeeping is sufficient for idempotent physical deletion, proposed as `object_deleted_at`, claim timestamp, attempt count, and a bounded non-sensitive last error code. Provider error bodies are never stored.
- Authorization/RLS/privacy and required configuration:
  - All new objects live in `private`; there are no anon/authenticated table grants.
  - Access is service-role only through narrowly scoped functions with pinned `search_path` and public execute revoked.
  - `owner_id` is derived by the authenticated Edge layer, never accepted as authoritative client data and never derived from `user_metadata`.
  - Only token hash and a non-secret key-version identifier are stored.
  - Affiliate URLs contain no credentials or fragments after application sanitization; the SQL layer rejects structurally invalid empty values.
